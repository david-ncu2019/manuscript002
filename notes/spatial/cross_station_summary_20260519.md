## Script Design

The script (`summarize_allstations.py`):
- Reads both JSON files using Python's `json.load()`
- Sorts data by improvement percentage for visual clarity
- Uses matplotlib for 2-panel figures (16$\times$ 8 inches, 150 dpi)
- Applies conditional coloring based on the `_recommended` flag in each JSON
- Prints summary counts to stdout
